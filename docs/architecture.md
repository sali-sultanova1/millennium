# Архитектура «Миллениума»

Проект состоит из публичного сайта и кабинета сотрудников. Django обрабатывает запросы и возвращает страницы на Django Templates. PostgreSQL хранит туры, заявки и учётные записи. JavaScript отвечает за избранное, сортировку фотографий и обновление индикатора новых заявок.

## Каталог и публикация

В [`catalog/models.py`](../catalog/models.py) описаны направление (`Destination`), тур (`Tour`) и фотография (`TourImage`). Одному направлению соответствует несколько туров, у каждого тура может быть несколько фотографий. Первая по порядку фотография используется как обложка.

Публичный [каталог](../catalog/views.py) показывает опубликованные туры из активных направлений. В поиске доступны будущие вылеты, включая сегодняшний день, и предложения без даты вылета. Для фильтрации по диапазону цены пользователь задаёт валюту и указывает, рассчитана цена на человека или на всю поездку.

Браузер сохраняет идентификаторы избранных туров в [`localStorage`](../catalog/static/catalog/favorites.js). При загрузке избранного Django возвращает актуальные карточки доступных туров.

## Заявки

[`Inquiry` и `InquiryTour`](../inquiries/models.py) связывают обращение с выбранными предложениями. Для каждого тура хранится копия его названия, направления, даты, цены и других условий на момент отправки. Так по старой заявке можно обсудить предложение, даже если карточку в каталоге уже обновили.

В [`create_inquiry`](../inquiries/services.py) запись заявки и выбранных туров происходит в одной транзакции. Уведомление о новом обращении, если оно включено, отправляется после сохранения данных. При ошибке доставки заявка остаётся доступна в кабинете.

В [кабинете](../manager/inquiry_views.py) назначение ответственного и смена статуса выполняются одним запросом к базе. Запрос сработает, пока заявка открыта и ответственный не назначен. Завершить обращение может ответственный за него сотрудник.

## Доступ к кабинету

Данные сотрудника хранятся в модели [`accounts.User`](../accounts/models.py). Группа «Менеджеры» получает [права Django](../manager/signals.py) при применении миграций. Сервер проверяет эти права перед показом данных и выполнением действий. Управление сотрудниками доступно владельцу с правами суперпользователя.

## Хранение фотографий

При локальном запуске файлы сохраняются в томе `media_data`. В [настройках Django](../config/settings.py) можно переключить хранилище на Yandex Object Storage. В базе сохраняются имена файлов и порядок их отображения.
